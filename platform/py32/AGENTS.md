# PY32 平台 Agent Guide

本文件适用于 `platform/py32/`；全仓契约见根 `AGENTS.md`，硬件规格与当前证据见 `docs/PY32F002A.md`，历史错误模式见 `docs/PY32_PORTING_RETROSPECTIVE.md`。

- 当前目标硬件为 PY32F002A + ST7789；芯片、显示、引脚或工具链变化必须先更新平台规格。
- PY32 专用实现、测试、构建规则、辅助脚本和厂商快照全部留在本目录，不得进入游戏、根 `third_party/` 或公共兼容层。
- 公共 framebuffer 始终为 128×64、1 bit、1024 字节；RGB565 转换只在显示驱动中完成。
- 厂商代码保留上游注释和来源信息；ArduGirl 新增注释使用中文。
- 固件能链接、能烧录、CPU 在运行、显示有画面、按钮可用、声音可听和存储可持久化是不同验收项，必须分别给证据。
- 单游戏构建使用 `GAME=<game-id>`。声称全游戏通过前，必须等待 `make PLATFORM=py32 test` 完整结束并依据最终汇总与退出码；单独修复后的成功不得改写最近一次全量结果。
- 诊断日志写入系统临时目录并在验证后清理，禁止在仓库根目录生成 `py32-*.log` 等临时文件。
- 冷构建只清理目标游戏对应的 `build/py32/<game-id>/`；除非任务明确要求全仓清理，不删除 Linux 或其他游戏缓存。
