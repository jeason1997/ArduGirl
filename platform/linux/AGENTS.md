# Linux 平台 Agent Guide

本文件适用于 `platform/linux/`；全仓契约见根 `AGENTS.md`，实现规格见 `docs/LINUX_SDL.md`。

- SDL2 是唯一 Linux 前端。已废弃的 terminal 实现、目标和兼容分支不得重新引入。
- SDL 类型只能出现在 Linux SDL 实现内部，不进入公共平台接口、兼容层或游戏。
- Linux runtime、存储与崩溃诊断应复用平台内公共实现，不复制游戏或兼容逻辑。
- Linux 专用源码、测试、构建规则和辅助脚本留在本目录。跨平台准备逻辑只有确实被多个后端共同使用时才进入根 `tools/`。
- `GAME=<game-id>` 必须只展开所选游戏及其依赖；未指定 `GAME` 的聚合构建或测试才能展开全部游戏。
- 测试存档、截图和诊断输出使用操作系统临时目录；正式游戏验收截图按 `games/AGENTS.md` 保存。
- 相关变更至少运行定向构建和测试；触及公共 Linux 构建模板时，还要执行空产物聚合构建或明确说明未执行原因。
