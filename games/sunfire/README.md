# Sunfire

第一人称太空飞行射击游戏，复用公共 ATMlib 四声道合成音乐。

状态：`partial`。现有截图记录了启动、菜单和飞行玩法，但截图输入尚未固化为自动回放；完整波次与长期音乐仍待验收。

构建并运行：`make PLATFORM=linux GAME=sunfire`

仅构建：`make PLATFORM=linux GAME=sunfire build`

定向测试：`make PLATFORM=linux GAME=sunfire test-sunfire`
